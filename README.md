# AvaliaZap Pro (Landing + Protótipo de Painel)

Site responsivo para apresentar uma solução de coleta de avaliações via WhatsApp com direcionamento para Google Meu Negócio.

## Estrutura

- `index.html`: página principal com seções de produto, funcionalidades, painel e formulário de contato.
- `styles.css`: estilos responsivos e layout profissional.
- `script.js`: interação do formulário de demonstração.

## Como executar

Como é um projeto estático, você pode abrir `index.html` diretamente no navegador ou executar:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.
